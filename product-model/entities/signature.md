# Signature

Name/content, type/default selection and ownership

## Information kept

- **Name** — The name used to identify the selected record to people.
- **Content** — Retained body of the communication.
- **Type** — Retained type selection used by the corresponding operation.
- **Default** — Whether this signature is selected by the implemented default lookup.
- **Owner** — The account responsible for this record.
- **Department** — The organizational scope retained on this record.
