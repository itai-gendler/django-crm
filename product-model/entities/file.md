# File

Filename/media location and attached subject; attachment records may share physical storage

## Information kept

- **Filename** — Display filename derived from the uploaded media path.
- **Media location** — The advertised media location; it does not itself establish private byte-delivery authorization.
- **Attached subject** — The record to which this attachment reference belongs.
- **Attached to Deal** — The retained Attach to the deal choice used when carrying selected inquiry files into its Deal.
