# History

Audit actor, represented subject, action/change description and time

## Information kept

- **Actor** — Account attributed to the recorded admin action.
- **Subject representation** — Retained display representation of the affected record.
- **Action** — Recorded add, change or delete action.
- **Change description** — Retained description of the admin change.
- **Time** — Timestamp recorded for the admin action.
