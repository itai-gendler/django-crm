# Transaction quality signal

Name, department, configured weight and explanatory information

## Information kept

- **Name** — The name used to identify the selected record to people.
- **Department** — The organizational scope retained on this record.
- **Weight** — Retained numeric contribution to the displayed quality score.
- **Description** — Retained descriptive content.
