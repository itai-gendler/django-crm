# Lead source

Name, department, email/source token and form/success configuration

## Information kept

- **Name** — The name used to identify the selected record to people.
- **Department** — The organizational scope retained on this record.
- **Email address** — Address or address list retained for correspondence and counterparty matching.
- **Source token** — Configured source identifier supplied by the website inquiry API.
- **Form configuration** — Configured public inquiry form presentation for this source.
- **Success destination** — Configured destination after public inquiry submission.
